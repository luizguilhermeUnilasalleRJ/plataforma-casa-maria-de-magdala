# Plataforma Casa Maria de Magdala

## Descrição

Projeto acadêmico desenvolvido para a Casa Maria de Magdala, com o objetivo de criar uma plataforma web composta por um site institucional e um sistema de gerenciamento para auxiliar nas atividades da ONG relacionadas ao HIV/AIDS.

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* Python
* Flask
* PostgreSQL
* Git e GitHub

## Estrutura

* `codigo/` — códigos do site e do sistema.
* `banco-de-dados/` — arquivos relacionados ao banco de dados.
* `evidencias/` — evidências do desenvolvimento do projeto.

## Instruções de uso

O projeto está em desenvolvimento. As instruções para instalação e execução serão adicionadas conforme as funcionalidades forem implementadas.
